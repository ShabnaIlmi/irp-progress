What I have actually run so far for my project, From Injected to Organic Failures. Each square below is one real task run. Tabs 1 to 3 are my main agent, Qwen3-8B: the pilot, the full run and the labels. Tab 4 is the four other agents I use to test transfer (RQ2), and tab 5 is where things stand.

Setup: BFCL v3 multi-turn, run with Ollama locally and on Kaggle (2×T4). Main agent Qwen3-8B; other agents Granite 4.1 8B, Llama 3.1 8B, Ministral 3 8B, Qwen3.5-27B.

2. Full run

After the pilot, Qwen3-8B ran all 800 BFCL tasks: 200 scenarios, each in four versions (base, missing function, missing parameter, long context).

All 800 runs are here, one square each. Orange squares failed, blue squares passed. The official checker agreed with my scoring on all 800.

3. Decisive turns

For each failed run, I went back one turn at a time, replaced the agent’s response with the correct one, and let it carry on. The earliest turn whose fix made the task succeed is the decisive turn.

Each square is one of the 708 failed runs. Purple squares got a decisive turn from replay. Grey squares had no single fixable turn, often because of two separate mistakes, so I left them unresolved instead of guessing.

decisive turn found, 300unresolved, 408

That is 42% coverage, and I report it next to every accuracy figure. Separately, five runs were excluded for context overflow, leaving 703 in the labelling pool. Six annotators now check sampled labels, three judgements per trace, without seeing the replay answer.

4. Other agents (RQ2)

To check whether localisers transfer to other models, I ran four more agents on 160 of the same BFCL tasks and labelled their failures with the same replay method as Qwen3-8B.

Each bar is one agent’s labelled failures. Purple means replay found a decisive turn, grey means unresolved. The agents fail at very different rates, which is part of what RQ2 tests.
